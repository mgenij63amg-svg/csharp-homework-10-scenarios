# Домашняя работа 10 Сценарии

Telegram ToDo бот на C#. Создание задачи проходит в личном чате за два шага: название и срок выполнения. Промежуточные значения сохраняются отдельно для каждого пользователя. Команда `/cancel` прерывает диалог без добавления незавершённой задачи.

## Требования и запуск

Нужны .NET SDK 8.0, доступ к NuGet при первом восстановлении пакетов и токен бота от [@BotFather](https://t.me/BotFather). Используется Telegram.Bot 22.5.1. Откройте `ToDoBot.sln` в Visual Studio с поддержкой .NET 8 или выполняйте команды из каталога решения.

```powershell
dotnet restore --locked-mode
dotnet build -c Release --no-restore
$env:TELEGRAM_BOT_TOKEN = Read-Host 'Токен бота'
dotnet run --project TelegramBot -c Release --no-build
```

Для Linux и macOS перед запуском задайте токен в текущей оболочке:

```sh
read -rs TELEGRAM_BOT_TOKEN
export TELEGRAM_BOT_TOKEN
dotnet run --project TelegramBot -c Release --no-build
```

После сообщения о запуске откройте личный чат с ботом и отправьте `/start`. Остановка приложения - `Ctrl+C`. Токен хранится в переменной окружения и не включается в исходники. Если переменная не задана, приложение завершится с пояснением.

## Команды

| Команда | Действие |
|---|---|
| `/start` | Регистрация пользователя; повторная команда сохраняет его задачи |
| `/addtask` | Начало сценария создания задачи |
| `/cancel` | Отмена текущего сценария |
| `/showtasks` или `/showtask` | Активные задачи со сроками и идентификаторами |
| `/showalltasks` | Все задачи, включая завершённые |
| `/completetask <id>` | Завершение своей задачи по идентификатору из списка |
| `/removetask <id>` | Удаление своей задачи |
| `/report` | Количество всех, активных и завершённых задач |
| `/help` | Справка по командам и сценарию |

Во время сценария доступна одна кнопка `/cancel`. Остальные сообщения обрабатываются текущим шагом. После завершения или отмены возвращается основное меню.

## Создание задачи

1. Отправьте `/start`, затем `/addtask`.
2. На запрос «Введите название задачи:» введите, например, `Подготовить домашнюю работу`.
3. На запрос срока введите дату, например, `25.05.2025`. Формат строго `dd.MM.yyyy`.
4. Бот подтвердит создание и покажет основное меню. Команда `/showtasks` выведет задачу со сроком.

Дата `25.05.20254`, несуществующий день `31.04.2025`, другой разделитель или нетекстовое сообщение оставляют диалог на шаге даты. Повторный ввод корректной даты завершает сценарий. Високосные даты проверяются календарём .NET. Прошедшие даты разрешены: в задании такого ограничения нет, а демонстрация использует этот случай.

Название должно содержать от 1 до 128 символов после удаления пробелов по краям. Команда вместо названия не принимается. На любом шаге `/cancel` очищает промежуточные данные; следующая `/addtask` начинает новый диалог.

## Структура решения

```text
TelegramBot/
  Program.cs                         запуск и long polling
  UpdateHandler.cs                   команды и маршрутизация сценариев
  BotKeyboards.cs                    основная клавиатура и кнопка отмены
  Models/                            ToDoUser, ToDoItem и состояние задачи
  Services/                          интерфейсы и сервисы пользователей и задач
  Scenarios/
    ScenarioType.cs                  None, AddTask
    ScenarioResult.cs                Transition, Completed
    ScenarioContext.cs               пользователь, текущий шаг и Data
    IScenarioContextRepository.cs    доступ к пользовательским контекстам
    InMemoryScenarioContextRepository.cs
    IScenario.cs
    AddTaskScenario.cs               шаги null, Name и Deadline
TelegramBot.Tests/                   автоматические проверки
```

`UpdateHandler` обрабатывает `/cancel` до передачи сообщения сценарию. При наличии контекста остальные команды не запускаются. `ProcessScenario` сохраняет контекст для `Transition` и удаляет его для `Completed`. `GetScenario` выбрасывает исключение, если обработчик не найден.

В шаге `null` пользователь помещается в `Data`, а текущий шаг меняется на `Name`. Затем имя сохраняется в `Data`, и начинается шаг `Deadline`. Метод `IToDoService.Add` вызывается после получения корректной даты и принимает `DateTime deadline`. Так отдельный шаг срока из пункта 6 дополняет первоначальный сценарий пункта 4.

Контексты хранятся в `Dictionary<long, ScenarioContext>`, дополнительные данные - в `Dictionary<string, object>`. Пользователи, задачи и незавершённые сценарии существуют до остановки процесса. После перезапуска данные теряются. Бот предназначен для личного чата.

## Автоматические проверки

```powershell
dotnet test -c Release
```

Тесты используют настоящий `TelegramBotClient` с подставным HTTP-транспортом. Они проверяют содержимое запросов `sendMessage`, клавиатуры, изменения контекста и задачи в сервисе; токен и соединение с Telegram для них не нужны. Проверяются корректный диалог, ошибочные даты, отмена на обоих шагах, изоляция пользователей, повторные сценарии, справка, команды просмотра, права на задачи и отмена операций через `CancellationToken`.

Для проверки с Telegram запустите приложение с собственным токеном и выполните диалог выше, затем повторите его с ошибочной датой и с `/cancel` на каждом шаге.

## Отправка на проверку

По [правилам курса](https://github.com/OTUS-NET/C-Sharp-Basic/blob/main/Homeworks/README.md) сдаётся ссылка на Pull Request или Merge Request. Рядом с каталогом исходников находится `ToDoBot.bundle` с двумя локальными ветками: `main` содержит базового бота, `feature/homework-10-scenarios` - изменения этой домашней работы. Чтобы сохранить разделение веток, восстановите репозиторий из bundle в новый каталог:

```powershell
git clone --branch main ToDoBot.bundle ToDoBotRepo
cd ToDoBotRepo
git switch --track origin/feature/homework-10-scenarios
$repoUrl = Read-Host 'URL вашего пустого удалённого репозитория'
git remote set-url origin $repoUrl
git push -u origin main
git push -u origin feature/homework-10-scenarios
```

Создайте Pull Request из `feature/homework-10-scenarios` в `main` и отправьте его ссылку преподавателю. Слияние выполняется после принятия работы. Для обычного запуска восстановление Git не требуется - достаточно каталога исходников.

Описание для Pull Request:

> Добавлена поддержка пользовательских сценариев с промежуточным состоянием в Dictionary. Команда /addtask запрашивает название и срок задачи; /cancel прерывает диалог и возвращает меню. Неверная дата повторно запрашивается без потери названия. Обновлены /help, клавиатуры, модель ToDoItem и IToDoService.Add. Добавлены автоматические проверки диалогов и изоляции пользователей.
